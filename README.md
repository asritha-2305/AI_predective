# AI-Based Predictive Maintenance System

## About the Project
This project uses Artificial Intelligence and Machine Learning to monitor motor health and predict machine conditions.

## Technologies Used
- Python
- Machine Learning
- Random Forest Algorithm
- Pandas
- NumPy
- Streamlit

## Input Parameters
1. Temperature
2. Vibration
3. Current

## Features
- Sensor data generation
- AI model training
- Machine condition prediction
- Interactive dashboard
- Sensor graphs

## How to Run
1. Install required libraries.
2. Run generate_data.py
3. Run train_model.py
4. Run streamlit run app.py

## Note
This is an educational simulation using synthetic sensor data.
